# Noxtyr — Game Design Document

## Концепт
**Noxtyr** — 2.5D Dark Fantasy Action RPG для Android.

### Сеттінг
- **Світ:** Velgrum — пост-апокаліптичне темне фентезі
- **Лор:** "The Arks have fallen. The dead do not rest. Velgrum bleeds."
- **Протагоніст:** Konstantin — "Not a hero. Just alive."

### Жанрові механіки
- Isometric action combat
- Система бафів/дебафів (bit-mask encoding)
- State Machine для анімацій
- Touch controls (virtual joystick + action buttons)

### Платформа
- Android (primary)
- Можливий порт на iOS/Desktop

### Візуальний стиль
- Темна палітра: #050508, #1a1a24, #3a3a48
- Isometric 2.5D з динамічним освітленням
- Піксель-арт естетика з сучасними ефектами
